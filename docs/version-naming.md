# Wayland Spectre — Version Naming Convention

## Theme

Releases are named after **gelatinous cubes**, each version evoking a distinct
elemental or magical variant. Names follow the **Elegant Thematic Compound**
style: short, fantasy-flavoured compounds that read as premium and instantly
recognisable.

## Convention

Each release uses the form:

> `vX.Y.Z <CompoundName> Gelatinous Cube`

Versions advance alphabetically by compound name, so the name itself signals
relative position in the release sequence.

## Release Assets

Each release ships with a matching **image** and **video** asset depicting its
gelatinous cube variant, attached to the corresponding Forgejo release.

Naming convention:

- `vX.Y.Z-<compoundname>.jpg`
- `vX.Y.Z-<compoundname>.mp4`
