Hi @zamundaaa,

I have a Dell UP3214Q (tiled 4K via DP MST, two 1920x2160 tiles) connected
to an NVIDIA RTX 5090 (open kernel modules, driver 595.58.03). This is one of
the setups this MR targets, so I would like to help test when the branch is ready.

In the meantime, here is my `drm_info` and KWin journal from a current boot
(KDE Plasma 6.6.3, Wayland session, Fedora 43 / Bazzite).

## Hardware summary

- **GPU:** NVIDIA RTX 5090 (GB202), nvidia-drm 0.0.0, open modules 595.58.03
- **Display:** Dell UP3214Q (serial K3R903CH034P)
  - DP-4 (connector 134): tile 1,0 of 2x1, 1920x2160@59.99, CRTC 81
  - DP-5 (connector 137): tile 0,0 of 2x1, 1920x2160@59.99, CRTC 100
  - Group ID: 1, Single monitor: yes
- **Secondary:** LG 27GL850 on HDMI-A-3, 2560x1440@99.95, CRTC 62
- **Kernel:** 6.17.7 (Fedora 43)
- **KWin behaviour:** currently treats each tile as a separate output (stock)

## Tile properties from drm_info

```
DP-4 (connector 134):
  TILE blob 186: Group ID 1, Single monitor: yes, 2x1 tiles, location 1,0, size 1920x2160

DP-5 (connector 137):
  TILE blob 163: Group ID 1, Single monitor: yes, 2x1 tiles, location 0,0, size 1920x2160
```

The NVIDIA driver correctly exposes the TILE property on both connectors with
matching Group ID. The tiles are 2x1 horizontal (left tile at 0,0, right at 1,0).

Note: DP-4 only advertises a single mode (1920x2160@59.99), while DP-5
advertises multiple fallback modes down to 640x480. This asymmetry may be
worth knowing about for the tile-matching logic.

## Note on related bugs

I have also filed [KDE bug 518698](https://bugs.kde.org/show_bug.cgi?id=518698):
on this hardware, when only the tiled display is connected (no secondary HDMI
monitor), the kwin_screencast effect fails to register at startup. Adding any
secondary monitor resolves it. This may be related to how KWin handles the two
tile connectors during startup.

The portal registration also fails with ELOOP
([xdg-desktop-portal #1953](https://github.com/flatpak/xdg-desktop-portal/issues/1953)):

```
Failed to register with host portal: Unable to open /proc/<pid>/root
```
